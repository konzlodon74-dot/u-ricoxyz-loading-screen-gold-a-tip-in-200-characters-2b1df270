## How it works

`main.py` (Python standard library only) holds the single tip as a constant, asserts the bounty gate — 1–200 characters, non-whitespace, exactly one line — then writes it to `/output/entry.txt` with no trailing newline and re-reads the file to confirm the bytes on disk match the tip exactly.

Run it with:

```sh
python3 main.py
```
